# OrbitPass — small usability feedback protocol

**Status: not conducted.** This is a template, not participant data.

Invite 5–10 consenting adult volunteers to try both fictional membership goals. Explain upfront that no money, real accounts or personal information is involved. Alternate task order between volunteers, reset between tasks, and avoid revealing the intended action counts. Ask: “Which direction felt harder, and why?” Optionally collect two effort ratings (1 easy–5 hard).

Use anonymous participant codes, task order, reported effort and short neutral observations. Do not collect names, emails, private browsing information or recordings. Report descriptive counts/medians and disagreeing views; a convenience sample is not statistically conclusive.
